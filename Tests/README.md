# آزمون‌های میزبان

`Build-Final.ps1` آزمون‌های برنامهٔ فعلی را اجرا می‌کند. فایل‌های این پوشه
مدل و ورودی مصنوعی دارند و وارد فریم‌ور دستگاه نمی‌شوند.

`scenario/BoardScenario.*` و `actuation/BoardOutputTest.*` برای بررسی رگرسیون
نگه داشته شده‌اند. موفقیت آن‌ها به معنی فعال‌بودن حالت آزمون در دستگاه نیست.
`hmi/verify-profile.ps1` نبود توابع آزمون در فایل اجرایی دستگاه را بررسی می‌کند.

فرمان مستقل هر مجموعه در `run.ps1` همان پوشه است؛ تست فلش با `flash/test.ps1`
روی حافظهٔ شبیه‌سازی‌شده اجرا می‌شود و به برد وصل نمی‌شود.
