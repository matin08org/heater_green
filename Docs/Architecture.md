# معماری برنامهٔ فعلی

ورودی برنامه `Core/Src/HmiMonitorMain.c` است. فهرست دقیق فایل‌های کامپایل در
`Build-HmiMonitor.ps1` تعریف شده؛ Build-Final آن را با FinalApplication اجرا می‌کند.

منطق مشترک فرمان‌ها به ترتیب BurnerRuntime، BurnerControl/CombustionCycle و
BoardActuation است. درخواست START با وضعیت واقعی سنسورها و پروفایل بررسی می‌شود؛
علت رد در Home و DIAG نمایش داده می‌شود. MANUAL به CO2 یا روشنایی وابسته نیست؛
AUTO به هر دو وابسته است. STOP درخواست گاز/جرقه را صفر می‌کند؛ اعمال رله‌ها از
مسیر غیرهم‌زمان مشترک SPI2/595 می‌گذرد.

| منبع | مالک |
|---|---|
| TIM1 / PA8 / PA9 | کنترل فاز فن و زیروکراس |
| TIM3 + TIM2 / PC8 / PC9 / PC6 | پالس، شمارش و جهت استپر مشترک |
| TIM4 / PB13 | بیزر |
| TIM5 + DMA2 Stream0 | ADC شش‌کاناله، ۲۰Hz |
| SPI1 + DMA | نمایشگر ST7796S، افقی 480×320، 16MHz |
| SPI2 | MAX6675 و 595 با مالکیت مشترک و حفظ Q0 |
| SPI5 | NRF24 و دریافت CO2 |
| USART1 PB6/PB7 | قرارداد RS485؛ ترنسیور فعلاً متصل نیست |

TC1 شعله، TC2 سمپل‌کولر، PA2/PA3 سیگنال و مرجع CO و PA4 دمای ME2 است.
NTC میکسر PA5 اختیاری است. Q1 جرقه، Q2 فن بزرگ، Q3/Q4 شیرهای نمونه، Q5 فن
توزیع، Q6 فن کوچک و Q7 درخواست شیر گاز است؛ خروجی‌های رله active HIGH هستند.
هال PB12 active LOW است؛ یک موتور مشترک ۱۶۰۰ پالس بین دو انتها حرکت می‌کند.
بعد از بوت مرجع اگزوز باید دستی تأیید شود. هال مشترک به‌تنهایی هویت انتها را نمی‌گوید.

آزمون‌های BoardScenario و BoardOutputTest فقط در Tests هستند و وارد برنامهٔ
دستگاه نمی‌شوند. بررسی فایل ELF در تست ساخت مانع لینک‌شدن آن‌ها می‌شود.
