# Main Board Cube

این پوشه تنها سورس مرجع پروژه است. برای شروع، همین فایل را بخوانید.

## وضعیت نسخه

برنامهٔ STM32F412 با نمایشگر افقی ST7796S، سنسورها، کنترل دمپر، رله‌ها و منطق
فرایند ساخته می‌شود. شبیه‌سازی داخل دستگاه و منوی آزمون بار از برنامه حذف شده‌اند.
START override فعال است: START با بررسی‌های رد‌شده مسدود نمی‌شود و فقط هشدار می‌دهد
(بخش START OVERRIDE در [وضعیت راه‌اندازی](Docs/Status.md)). خروجی‌ها همچنان به تأیید EXHAUST،
سنک فاز فن و جدول CCR اندازه‌گیری‌شدهٔ فن وابسته‌اند. گزارش دقیق در
[وضعیت راه‌اندازی](Docs/Status.md) و فایل‌های تولیدی readiness.json قرار دارد.
این پاک‌سازی، مجوز فعال‌سازی خروجی‌ها یا تأیید عملکرد فیزیکی نیست.

## ساخت و بررسی

از PowerShell در همین پوشه اجرا کنید:

```powershell
.\Build-Final.ps1
.\Program-Final.ps1 -CheckOnly
```

فرمان اول سورس، تصاویر و فونت‌ها را می‌سازد، آزمون‌های میزبان را اجرا می‌کند و
فایل‌های متناظر پردازنده و حافظهٔ خارجی را در `Release/FinalV1` می‌گذارد.
فرمان دوم فقط فایل‌ها را بررسی می‌کند و به برد وصل نمی‌شود.

پیش‌فرض ابزارها STM32CubeIDE 2.1.1 ARM GCC و CodeBlocks MinGW GCC در ویندوز است.
برای مسیر متفاوت از `-Tools` و `-HostCompiler` استفاده کنید. مسیر ساخت معتبر
`Build-Final.ps1` است؛ تنظیمات قدیمی CubeIDE و برنامه‌های قدیمی حذف شده‌اند.
فایل `.ioc` فقط مرجع تنظیم پایه‌های اولیه است؛ بازتولید آن جایگزین تنظیمات زمان
اجرای ADC، تایمرها و DMA در سورس نهایی نیست.

## ساختار

| مسیر | کاربرد |
|---|---|
| `Core` | سورس برنامهٔ فعلی و درایورهای برد |
| `Drivers` | HAL و CMSIS با مجوزهای اصلی سازنده |
| `Libraries/Hmi` | رابط و کتابخانهٔ نمایشگر فعلی |
| `Assets` | تنظیمات برد، تصاویر، نقشه‌ها و شواهد اصلی |
| `Tools/Hmi` | ابزار تولید تنظیمات، فونت و منابع تصویری |
| `Tests` | تست‌های مستقل میزبان؛ مدل‌های مصنوعی فقط در این پوشه‌اند |
| `Docs` | وضعیت، معماری و قرارداد RS485 |
| `Backups` | پشتیبان واقعی فلش خوانده‌شده از برد؛ وارد Git نمی‌شود |
| `Debug` / `Release` | خروجی تولیدشده؛ سورس نیست و وارد Git نمی‌شود |

## پروگرام و بسته‌بندی

پس از ساخت موفق و بررسی وضعیت نسخه، `Program-Final.ps1` هر دو حافظه را با هم
پروگرام و بازخوانی می‌کند. اجرای بدون `-CheckOnly` به سخت‌افزار متصل می‌شود.
فایل CPU و assets باید از یک بیلد باشند. لودرهای 1MHz و 250kHz همراه پروژه‌اند.
`Package-Delivery.ps1` فقط آخرین بیلد بررسی‌شده را بسته‌بندی می‌کند.

## مجوزها

مجوزهای وابستگی‌ها حفظ شده‌اند. برای کد اختصاصی پروژه مجوز انتشار عمومی تعیین
نشده است. حق انتشار کد، نقشه‌های صاحب پروژه و فونت تولیدی پیش از عمومی‌کردن
مخزن باید مشخص شود.
